# 0123 — Report what hexmesh changed in gmsh's mesh: corrections recorded, written elements stated

- **Status:** ready
- **Decision:** [0046 — gmsh meshes; hexmesh corrects node positions and says so](../decisions/0046-gmsh-meshes-hexmesh-corrects.md), rule 5
- **Depends on:** none.  Can run before or after 0122.

Ground rules for all tasks: [README](README.md#ground-rules).

**Why.**  Decision 0046: gmsh creates the elements; hexmesh may move
nodes onto the exact geometry, and the user must be able to see exactly
where it did.  Today the projector keeps a per-fitting
`projection_report` (`hexmesh/assembly/assembler.py`) and warns beyond
`WALL_PROJECTION_WARN_MOVE`, but the record isn't part of the report a
user reads, and second-order wall nodes aren't counted.

**Where.**  `hexmesh/assembly/assembler.py`, the quality report and
the manifest (`<stem>.roles.json`, or the build manifest: whichever is
the user-facing record; say which in *Agent notes*), `validate()`,
`API.md`, `docs/GUIDE.md`, `tests/`.

**Do.**
1. **Corrections, per fitting:** nodes moved (first order; second-order
   wall nodes placed), the largest move (absolute, in local wall radii,
   in local edge lengths).  Always present in the quality report and the
   manifest, with an explicit "none" for fittings without corrections.
   No new warning; the large-move warning stays.
2. **Written elements:** the mechanism for decision 0046's notice,
   ready for task 0124: a per-fitting flag that, when set, makes
   `validate()` give a notice (not a warning; add a notice channel if
   none exists, and say how it is surfaced in Python, the CLI and the
   agent layer) and puts "N elements written by hexmesh, not generated by
   gmsh" in the report and manifest.  Nothing sets the flag yet; test it
   with a private stub.
3. **GUIDE:** a short paragraph "What hexmesh changes in gmsh's mesh",
   in the user's words: gmsh meshes; hexmesh moves wall nodes onto the
   exact pipe walls at junctions, and reports each move.

**Accept.**
- Every built example's report lists its corrections (or "none"); the
  numbers match `projection_report`.
- The notice mechanism tested with a stub; no fitting sets it.
- Meshes unchanged (byte-identical); full suite: no new failures.
- If the manifest's schema changes, its version and the agent schema
  follow decision 0040's rules.

**Out of scope.**  The opt-in itself (task 0124); new corrections.
