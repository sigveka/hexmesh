# LDV measurements: Taylor, Whitelaw & Yianneskis (1981)

`taylor_1981_table1.csv` is Table I of NASA Contractor Report 3367,
pp. 12–18: the laminar flow at Re 790 in a 90° square bend. The source is
[NTRS 19810007898](https://ntrs.nasa.gov/citations/19810007898); NTRS
rates it "GOV_PUBLIC_USE_PERMITTED".

- **Transcription:** done by hand from the page images (2026-11-06, task
  0072).
- **Check:** every number that the PDF's text layer reads cleanly matches
  the transcription. The garbled ones were read from the images.
- **Missing stations:** X_H = +2.50 (in a different layout, with V and W
  ×10²) is not transcribed.

The file's header defines the columns. The report gives the measurement
errors (its §2.3):
- V_c: ±0.8 %;
- U/V_c: systematic up to 3 % near velocity gradients (under 1 % elsewhere),
  random ±1–3 %;
- gapwise positions: ±0.2 mm.
